# 🛡️ Smart Shift Management

מערכת חכמה לשיבוץ משמרות (אבטחה, רפואה, ומוקדים), עם מנוע שיבוץ אלגוריתמי דטרמיניסטי שמסביר בפירוט כל החלטה שהוא מקבל. המערכת חוסכת שעות של עבודה ידנית ומונעת טעויות, תוך שמירה מלאה על הוגנות, שקיפות, וחוקי עבודה קשיחים.

🌍 **דמו חי ומלא:** [הפעל הדגמה (ללא צורך בהרשמה)](https://shd-git-main-omergot5s-projects.vercel.app)

---

## ⚡ הפיצ'רים המרכזיים
* 🤖 **מנוע אלגוריתמי הוגן:** מקצה משמרות אוטומטית לפי פניות, עומס קודם, שעות מנוחה והעדפות השומר. הכל שקוף, מנומק ודטרמיניסטי 100%.
* 📱 **ממשק משתמש פרימיום (Mobile-First):** תצוגה נקייה למאבטחים ולמנהלים, עם כרטיסי תורנות צבעוניים ושורת הוגנות אישית אל מול צוות העובדים.
* 📴 **Offline Ready:** המערכת מגובה ב-`localStorage` ותומכת בעבודה מלאה גם כשהרשת נופלת, אידיאלי לסביבות אבטחה ומוקדים (מצב טיסה).
* 🔄 **UndoBar מיידי:** ביטול פעולות (הסרה, אישור, מחיקה) בשבריר שנייה בלי חלונות אישור (Confirm) מעיקים - לחוויית עבודה רצופה ומהירה.
* 📸 **ייצוא ושיתוף:** ייצור סידור עבודה שבועי כתמונה איכותית (PNG) ושיתוף מהיר ישירות מתוך הדפדפן (כולל תמיכה מלאה בכיווניות שעות העבודה ב-RTL).
