## 🎯 החוק היחיד

> **שום כיתוב בממשק לא נושא שם של יכולת. כל כיתוב נושא שם של פעולה שהמשתמש מבצע.**

"שיבוץ חכם" מתאר את מה שהמערכת עושה. "סדר לי את השבוע" מתאר את מה שהמשתמש רוצה. השני מנצח תמיד — גם כשהראשון מדויק יותר טכנית, וגם כשהוא קצר יותר.

מבחן מהיר לכל מונח חדש: **האם משתמש שרואה אותו בפעם הראשונה יודע מה יקרה כשילחץ?** אם צריך להסביר — המונח נפסל.

## 🔀 פרופילים — הסיבה שהקובץ הזה קיים

`terms.js` בנוי כמפה אחת עם שכבת דריסה לכל פרופיל:

```js
const PROFILE_TERMS = { civil: {}, army: {} };
setTermProfile("army");   // מיזוג על BASE
t("nav.shifts");          // → המונח הצבאי
```

**היום שתי השכבות ריקות** — כל הפרופילים מקבלים את אותם מונחים. זה מכוון: התשתית נבנתה באבן דרך א' כדי שהפרופיל הצבאי באבן דרך ב' **לא יחייב נגיעה באף מסך**. כשיגיע הזמן, ממלאים את `PROFILE_TERMS.army` וזה הכול.

## ✍️ כשמוסיפים מונח

1. **תמיד ב-`terms.js`** — אף מחרוזת ניווט לא נכתבת ישירות ב-JSX. פיזור מחרוזות הוא בדיוק מה שיהפוך את הפרופילים לבלתי אפשריים.
2. **פועל בגוף ראשון** לפעולות ראשיות — "סדר לי", "שלח", "אבנה בעצמי".
3. **לעדכן את הטבלה כאן** באותו commit.
4. **לבדוק מול הבנדל, לא מול המקור** — `grep` על `src/` מפספס מונחים שנכתבו במקום אחר. אחרי בנייה, חיפוש בתוך `dist/` תופס את מה שבאמת מוצג.
