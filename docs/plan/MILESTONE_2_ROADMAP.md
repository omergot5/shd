# 🚀 אבן דרך ב': מפת דרכים והתאמה מתקדמת (Roadmap)

אבן דרך זו מתמקדת בהרחבת המערכת לפרופילים מגוונים (אבטחה, צבא, רפואה, מוקדים) ושליטה מעמיקה במשקולות וסוגי משימות.

---

## 🎯 תכולת אבן הדרך

### 1. סוגי תורנות וניקוד נטל מותאם
- הגדרת סוגי משמרות עם רמת קושי / נטל שונה (למשל: סיור = 1.5x, שמירה בשער = 1.0x, כוננות = 0.5x).
- מנוע השיבוץ יאזן לא רק כמות שעות, אלא **עומס מצטבר כולל** בין כל אנשי הצוות.

### 2. סבב הוגן לפי סוג משימה (Fair Rotation per Shift Type)
- מעקב ייעודי על תורנויות "פחות מועדפות" (כמו סופי שבוע / שבתות / לילות).
- אלגוריתם שמוודא שאף עובד לא מקבל שתי שבתות רצופות או עודף לילות.

### 3. משימות אד-הוק ואירועים מיוחדים
- הוספת תקנים זמניים ואירועים חריגים ללא שינוי התבנית השבועית הקבועה.

### 4. ניהול היעדרויות וחופשות מאושרות
- מודול בקשות חופשה / מילואים / מחלה.
- חסימה אוטומטית של שיבוץ עובד בתקופת היעדרות מאושרת עוד בשלב הגשת הזמינות.

### 5. פרופילי פעילות (צבא / אבטחה / מוקד / מסעדות)
- שימוש בתשתית `src/lib/terms.js` להתאמת המונחים והחוקים בלחיצת כפתור לפי ענף הפעילות.

### 6. גרסאות סידור ואישורי קריאה (Read Receipts)
- תיעוד היסטוריית שינויים בסידור שפורסם.
- אינדיקציה לאחמ"ש: מי מהשומרים פתח וצפה בסידור המשמרות שנשלח.

### 7. ייצוא והדפסה מתקדמת
- תבנית PDF נקייה ומוכנה להדפסה ותלייה בלוח המודעות.
