## 🛡️ כללי איכות וביצוע (Execution Rules)
1. **עצמאות ובדיקה עצמית:** כל משימה נבדקת עם בדיקות יחידה ייעודיות.
2. **איכות חובה:** אחרי כל משימה `npm test` חייב לעבור ו-`npm run build` חייב להצליח.
3. **דטרמיניסטיות:** אלגוריתם השיבוץ חייב להישאר 100% דטרמיניסטי ללא `Math.random`.
